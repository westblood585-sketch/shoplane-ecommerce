# Tanıtım Videosu Dosyaları

Bu klasöre giriş tanıtım videosu yükleyin.

## Desteklenen Formatlar
- MP4 (.mp4)
- WebM (.webm)
- Ogg (.ogv)

## Dosya Önerileri
- Boyut: Max 50MB
- Format: MP4 (en uyumlu)
- Uzunluk: 30-120 saniye önerilir
- Çözünürlük: 1920x1080 veya 1280x720

## Örnek Video Adı
- `intro-video.mp4`
- `welcome-video.mp4`

Video yüklendikten sonra, bileşen otomatik olarak oynatacaktır.
